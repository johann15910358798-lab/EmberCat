# 使用指南

[返回首页](../README.md)

## 安装与更新

发布包适用于 Apple Silicon Mac，要求 macOS 14 或更高版本。到 [GitHub Releases](https://github.com/johann15910358798-lab/EmberCat/releases/latest) 下载 DMG，将应用拖入「应用程序」后启动。

菜单中的「检查更新…」会检查最新正式版本；「自动检查更新」「自动下载并安装」可以分别调整，选择会保留。0.6.15 开始支持自动更新，0.6.14 及更早版本需手动安装一次新版。

当前应用采用 ad-hoc 签名，未使用 Apple Developer ID 或公证。更新清单和 ZIP 另外使用 Sparkle EdDSA 签名，详见[发布流程](updates.md)。

## 菜单栏宠物

点击或右键点击宠物，打开菜单。首次启动默认使用黑猫；「形象」可以切换为玛奇玛，选择会保存。

- **黑猫**：站立、行走、奔跑、滚动，步频随实时输出速度连续变化。输出停止后减速站稳。
- **玛奇玛**：步行、快走、跑步、轮滑、滑板、自行车、摩托车、跑车和飞行背包。输出速度决定动作档位，同一档的播放节奏保持固定。
- **显示实时速度**：在宠物旁显示单行 `tok/s`，使用与动作相同的输出速度。
- **动作预览…**：用模拟速度观看动作、加减速和跨档切换。实际菜单栏继续读取真实会话。

## 屏幕顶部特效

打开「刘海特效」，通过「特效样式」选择流焰、Matrix 代码雨或仓鼠发电机。有刘海时按系统报告的位置适配；无刘海时显示在屏幕顶部中央。

「特效设置与预览…」在深色、纯白和多色背景下展示模拟输出。拖动参数即时预览，点击「保存并应用」后才影响桌面效果；「恢复默认」也需保存后生效。切换样式会保留未保存的草稿，关闭窗口再打开则载入已保存设置。

三个效果都保持点击穿透。真实输出归零后淡出并停帧；关闭或休眠时停止绘制。系统开启「减少动态效果」后保留静态反馈。

### 仓鼠发电机

两侧仓鼠随输出速度平滑换挡，能量条由冷白变蓝、转紫，最高档略微泛红。条内能量连续流动，外部随机放电；悬浮与短促微颤随放电联动。

鼠标移到能量条或任一侧仓鼠时，整组淡出隐藏；移开后恢复。开启「减少动态效果」后，这项交互仍然有效。

| 参数 | 默认值 | 范围 |
| --- | --- | --- |
| 能量条粗细 | 100% | 65%–145% |
| 能量流速 | 100% | 25%–250% |
| 电弧强度 | 100% | 0–200% |
| 刘海距离 | 6 pt | 6–36 pt |
| 仓鼠大小 | 100% | 70%–150% |
| 两侧间距 | 5 pt | 0–24 pt |
| 仓鼠动画速度 | 1.00× | 0.50×–2.00× |
| 悬浮与放电微颤 | 开 | 开／关 |

能量流速和仓鼠动画速度独立调节，拖动时保持动作连续。预览区域和设置窗口保持固定尺寸，完整特效在内部适配；桌面浮层仍会根据仓鼠大小和间距扩展。

### Matrix 代码雨

代码从刘海下沿落下，向黑洞汇聚，在吸积盘中绕行、碎裂和消散。黑洞大小随 `tok/s` 变化，并有轻微呼吸；配色跟随 macOS 深浅外观。

鼠标经过时，黑洞和盘面代码一起虚化，移开后恢复。中心保持暗色，独立背景雨继续下落。

| 参数 | 默认值 | 范围 |
| --- | --- | --- |
| 大小上限 | 175% | 75%–250% |
| 引力强度 | 180% | 50%–300% |
| 代码密度 | 200% | 40%–300% |
| 与刘海距离 | 半嵌入 | 向下 0–64 pt |
| 吸积盘宽 | 100% | 40%–180% |

### 流焰

刘海外沿的流光和向下火焰随输出变化。「火焰质感」调整材质，「速度与颜色」定义各速度区间的颜色。

| 参数 | 默认值 | 范围 |
| --- | --- | --- |
| 亮度 | 100% | 40%–180% |
| 亮芯范围 | 50% | 0–100% |
| 通透度 | 40% | 0–100%，越大越透明 |
| 焰尾长度 | 100% | 35%–135% |
| 扰动 | 100% | 0–200% |
| 流速 | 100% | 25%–250% |

颜色支持 1–8 个速度区间，第一档从 0 开始，后续起点依次增加。可通过系统选色器或 `#RRGGBB` 设置颜色。默认低速金黄、中速红色、高速蓝色；0 tok/s 时熄灭。

## Dock 小猫

「绕 Dock 跑圈」默认关闭。开启后，黑猫沿 Dock 四边绕行，速度跟随输出；停下时坐在 Dock 上沿，眼睛跟随鼠标。

「脚印荧光色」提供五种预设，也可通过「自定义…」选色。旧脚印会自然淡出，关闭效果、Dock 隐藏或休眠时清理。

部分布局需要辅助功能权限才能定位 Dock，菜单会显示「需辅助功能权限定位 Dock」和「允许…」。该功能读取 Dock 的位置和尺寸，不移动 Dock。系统开启「减少动态效果」后显示静止黑猫。

## Token 来源与测速

进入「Token 来源」，左侧选择来源，右侧查看实时输出速度、估算份额、今日输出 token、今日会话、生成或工具状态，以及本地记录位置。

测速由 [Agent Speed 核心](../Vendor/UPSTREAM.md)提供，以约 3 秒窗口统计本地会话的输出。`tok/s` 是近期输出速率，今日输出量是累计值；无法直接测量的部分会标记为估算。「已发现来源」表示来源类型数量，不是同时运行的 Agent 数量。

支持的来源为 Codex、Claude Code、Claude Desktop、DSH、OpenCode、Gemini CLI、oh-my-pi、Antigravity、WorkBuddy、WorkBuddy AI、ZCode、Kimi Code CLI 和 Grok Build。来源需要在本机留下可识别的记录；Claude Desktop 的普通云端聊天不在本地会话监控范围内。

### 没看到速度或来源时

- 首次启动可能正在扫描本地会话，等扫描完成后再看来源详情。
- 已发现目录但没有当天会话时，页面会显示「今日暂无会话」。
- 等待输出、执行工具期间，输出速度可能为零。
- 格式不支持、记录位置不可用时，按来源页面显示的状态和路径排查。

测速定义和来源路径的详细约定见 [METRICS.md](../Vendor/METRICS.md)。
