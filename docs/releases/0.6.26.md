# EmberCat 0.6.26 · 平滑慢速待机

Build 42 · 2026-11-11

修复黑洞与仓鼠发电机在零输出时慢得像停住的问题，让待机动画保持连续、可见的慢动作。

## 本次改动

- 取消代码雨和能量流的重复减速，零速时继续平滑流动，恢复输出后随速度加快。
- 仓鼠慢速播放增加原始帧之间的混合过渡，消除长时间停在一帧再跳动的观感；默认待机约 2.13 秒完成一轮。
- 仓鼠每段动画在自身帧序列内平滑循环，正常输出速度下保留原始 GIF 时序。
- 悬浮和黑洞呼吸保持可感知的慢速变化；系统「减少动态效果」下仍为静态待机。

沿用已有特效参数和代码密度设置，鼠标经过、移开和关闭特效的行为保持一致。

## 验证与安装

原生流焰、Matrix 和仓鼠发电机回归通过，覆盖待机时钟、窗口刷新、悬停恢复、参数和休眠恢复。以 60 fps 分别检查仓鼠 0.5×、1×、2× 播放，每组 120 帧均有仓鼠画面变化；循环与减少动态效果检查通过。构建和 5,952 帧资源检查通过。

原生验收在无刘海的外接屏完成，实体刘海尚未实测。适用于 Apple Silicon Mac、macOS 14 或更高版本；0.6.15 及后续版本可通过「检查更新…」获取本版。DMG 与 ZIP 包含相同应用。

应用采用 ad-hoc 签名，更新清单和 ZIP 使用 Sparkle EdDSA 签名；未使用 Apple Developer ID 或公证。
