# EmberCat 0.6.21

Build 37 · 2026-11-05

Matrix 代码雨中的字符会进入吸积盘，继续绕行、拉伸和碎裂，并形成盘面的弯曲光带。黑洞大小随输出速度变化，中心灯移除，暗核保持干净。

## 新增与调整

- 下落字符在交接到盘面后保留同一字形，逐渐收缩、碎裂并化成荧光。盘面发光由这些字符驱动，数字、字母与片假名可以沿弧面辨认。
- 保留倾斜的细前景盘带、上下弯曲弧面与细光子环。深色使用荧光绿和冷白高光，浅色使用墨青绿；暗核内部不显示字符。
- 黑洞实际大小由平滑 tok/s 决定，原大小滑杆改为「大小上限」。默认上限下，20 / 90 / 180 tok/s 的暗核直径约为 30 / 38 / 46 pt。
- 移除中心灯与对应滑杆，改为约 3.8 秒一轮、峰谷差约 4% 的轻微本体呼吸。
- 鼠标经过时，暗核、盘带与盘内代码整体虚化，移开后恢复。独立背景雨继续竖直下落，不参与吸积；桌面浮层保持点击穿透。
- 五参数、连续调速、旧配置兼容、减少动态效果、归零停帧和休眠恢复保留。旧中心灯字段会被忽略，其余保存值继续使用。
- 放缓代码进入盘面的收拢过渡，让雨流与盘内字形衔接；修复命令行导出 Matrix 预览的初始化问题。

| 参数 | 默认值 | 可调范围 |
| --- | --- | --- |
| 大小上限 | 175% | 75%–250% |
| 引力强度 | 180% | 50%–300% |
| 代码密度 | 200% | 40%–300% |
| 与刘海距离 | 半嵌入 | 向下 0–64 pt |
| 吸积盘宽 | 100% | 40%–180% |

菜单入口为「刘海特效 → Matrix 代码雨」及「特效设置与预览…」。预览使用模拟 tok/s，保存并应用后才影响顶部特效。

## 安装与验证

适用于 Apple Silicon Mac，macOS 14 或更高版本。0.6.15 及后续版本可通过「检查更新…」或自动更新获取本版；更早版本需要手动安装。DMG 与 ZIP 包含相同应用。

本轮检查覆盖 243 组尺寸与运动参数、同一字符的交接与完整碎裂、连续变速、五参数保存重开、暗核遮挡、悬停与原生生命周期，原火焰回归通过。当前原生验证环境为无刘海外接屏的顶部锚点，尚未完成实体刘海屏的实机视觉验收。可读字形采用艺术化的尺寸和轨道补偿。

应用沿用 ad-hoc 签名，未使用 Developer ID 或 Apple 公证；更新清单和 ZIP 另有 Sparkle EdDSA 签名。
