# EmberCat 0.6.24 · 新版面板与对话级测速

Build 40 · 2026-11-06

展开面板重新整理了布局，常用设置更紧凑；「Token 来源」现在可以查看每条对话的输出速度和运行状态。

## 本次改动

- 顶部突出宠物、实时速度和输出状态；菜单栏形象、刘海特效、Dock 与脚印颜色按组展示，减少多余留白。
- 三种刘海特效完整并排显示，当前样式带勾选标记；动作预览与特效设置使用独立入口。
- 自动检查更新、自动下载并安装及退出入口移入底部「更多」菜单，已有偏好继续保留。
- 来源详情增加「对话与子 Agent」列表，逐条展示项目、短记录 ID、模型、当前速度和状态。同项目、同模型的多条对话分别保留，子 Agent 按父子关系缩进展示。
- 点击对话可展开完整模型、最近活动时间、最近响应均速和记录标识，并可复制完整标识。

对话列表沿用测速核心的近期活动范围：近 10 分钟有活动或正在生成的记录，以及关联的父对话。今日会话数统计全天。每行只显示该记录自身的速度，来源总速度继续使用核心汇总值。

## 验证与安装

本地构建、5,952 帧资源检查、6 项独立 Swift 会话逻辑检查及深浅色原生界面检查通过。真实本地记录检查确认独立速度与父子层级，已安装版本的来源列表入口经人工确认可用。

适用于 Apple Silicon Mac、macOS 14 或更高版本。0.6.15 及后续版本可通过「检查更新…」或自动更新获取本版；更早版本需手动安装。DMG 与 ZIP 包含相同应用。

应用沿用 ad-hoc 签名，更新清单和 ZIP 使用 Sparkle EdDSA 签名；未使用 Apple Developer ID 或公证。
