# EmberCat 0.6.19

Build 35 · 2026-11-04

新增 Matrix 黑洞代码雨刘海特效。代码沿刘海下沿竖直落下，受中央黑洞吸引后汇聚、旋转并吸入；更暗、更细的背景雨独立下落，保留画面的层次。

## 新增与调整

- 菜单「刘海特效 → 特效样式」可切换流焰与 Matrix 代码雨，选择会保存；已有用户继续沿用流焰或此前保存的选择。
- 黑洞默认半嵌入刘海，可向下移动至完全脱离，最远下移 64 pt。吸入路径、洞缘微光和遮挡随位置变化，脱离后刘海中央恢复落代码。
- 左侧代码从侧缘进入黑洞后方，右侧从前方汇入同向旋转，避免左侧入口反向兜弯；洞口保留少量尚未吸完的旋转字符。
- 配色自动跟随 macOS 外观。深色保留荧光绿，浅色使用更清晰的墨青绿并减弱光晕；黑洞内部始终保留亮绿。
- 「特效设置与预览…」提供三种背景、模拟速度和四个实时滑杆。预览参数在保存并应用后才影响顶部特效。
- 输出 tok/s 同时驱动代码数量与流速；归零、关闭或屏幕休眠后停止绘制，支持系统减少动态效果。
- 保留现有测速来源、宠物动作、Dock 小猫、荧光脚印及 Sparkle 自动更新。

| 参数 | 默认值 | 可调范围 |
| --- | --- | --- |
| 黑洞大小 | 175% | 75%–250% |
| 引力强度 | 180% | 50%–300% |
| 代码密度 | 200% | 40%–300% |
| 与刘海距离 | 半嵌入 | 向下 0–64 pt |

## 安装与更新

适用于 Apple Silicon Mac，macOS 14 或更高版本。0.6.15 可通过菜单「检查更新…」或自动更新获取本版；0.6.14 及更早版本需要手动安装一次。

手动安装使用 DMG，Sparkle 使用 ZIP；两者包含相同应用。应用使用本地 ad-hoc 签名，未使用 Developer ID 或 Apple 公证；更新清单和 ZIP 另有 Sparkle EdDSA 签名。

预览和验收使用明确标注的模拟 tok/s。当前实机为无刘海外接屏，128/180/255 pt 刘海及参数极值由渲染和几何检查覆盖，尚未完成实体刘海屏真机验收。

Token 检测与测速核心来自 Agent Speed（MIT）；源码和应用内保留上游及 Sparkle 的许可声明。
