# EmberCat 0.6.25 · 零速待机与黑洞密度修复

Build 41 · 2026-11-11

Agent 等待输出或执行工具时，黑洞和仓鼠发电机继续很慢地运动。黑洞代码密度按设置保持，低速时也能看到预览中设定的完整代码墙。

## 本次改动

- 黑洞与仓鼠发电机在 0 tok/s 时保留待机动画，启动、重新开启及休眠恢复后都能显示；恢复输出后平滑加速。
- 仓鼠 GIF、能量流动、悬浮及黑洞呼吸在待机时放慢，测速仍显示真实输出。
- 代码密度不再受低输出率的代码列数预算压低；密度滑块控制字符数量，tok/s 继续控制流速和黑洞大小。
- 预览的零速按钮显示「慢速待机」，与顶部浮层行为一致；零速时保存的参数立即应用。
- 关闭特效或休眠时停止绘制，系统「减少动态效果」下保留静态待机，鼠标经过与移开仍能响应。

原有特效参数继续保留。流焰沿用 0 tok/s 时熄灭的行为。

## 验证与安装

原生流焰、Matrix、仓鼠发电机及设置预览回归通过，包括零速启动、待机时钟、参数保存、样式切换、窗口重开、悬停恢复和休眠恢复。5,952 帧及应用资源检查通过。按现有 300% 密度进行画面对照，180 tok/s 的渲染与修改前完全一致。

原生验收在无刘海的外接屏完成，实体刘海尚未实测。适用于 Apple Silicon Mac、macOS 14 或更高版本；0.6.15 及后续版本可通过「检查更新…」获取本版。DMG 与 ZIP 包含相同应用。

应用采用 ad-hoc 签名，更新清单和 ZIP 使用 Sparkle EdDSA 签名；未使用 Apple Developer ID 或公证。
