# EmberCat 0.6.17（历史草稿）

Build 33 · 2026-11-03

此本地草稿未作为 GitHub 正式版本发布；最终 Matrix 方案见 [0.6.19](0.6.19.md)。以下保留当时的设计记录。

Matrix 的代码不再只有向下落的一种路径。竖直雨幕之间新增交错螺旋、横向弧流和由远及近的纵深穿梭，在同一个效果内自然轮换主次。

- 两股字符带横向穿行并绕转，交叉处按前后深度叠放。
- 亮头带着一束代码沿弧线扫过，下一轮从另一侧进入。
- 字符从中心深处向外掠出，接近时变大、变清晰，再逐渐消散。
- 中央雨幕适当让出空间；刘海轮廓流光和周围下落代码持续保留。
- 原有样式选择、火焰参数、真实测速、归零停帧与减少动态效果继续生效。

菜单入口仍为「刘海特效 → Matrix 代码雨」。预览和导出画面明确使用模拟 tok/s。源码和本地安装包不代表 GitHub Release 已发布；当前实机验证环境为无刘海外接屏，其他刘海尺寸由模拟几何覆盖。
