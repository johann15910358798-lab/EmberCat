# EmberCat 0.6.14

Build 30 · 2026-11-03

本版为刘海火焰增加写实流焰、连续描边和可滑动调节的质感参数，保留 Dock 小猫、荧光脚印与玛奇玛连续动作。

## 新增与改进

- 六个实时滑杆：亮度、亮芯范围、通透度、焰尾长度、扰动、流速。亮芯与亮度都可以自由调高或调低。
- 火焰沿刘海两侧和下沿连续描边，半透明焰尾向下卷动；在深色、纯白和多色背景中提供共同预览。
- 支持 1–8 个自定义速度区间，每档可通过系统选色器或 HEX 设置颜色；跨档平滑过渡，0 tok/s 熄灭。
- 编辑时即时预览，点击「保存并应用」后保存设置并应用到实际覆盖层；修改流速保持动画连续。
- 包含此前完成的 Dock 跑圈、可自定义颜色的荧光脚印、透明待机小猫与鼠标视线跟随。

## 安装

适用于 Apple Silicon Mac，macOS 14 或更高版本。下载 `EmberCat-0.6.14.dmg`，退出正在运行的 EmberCat，再将镜像中的应用拖入 Applications。

此包使用本地 ad-hoc 签名，未使用 Developer ID 签名，也未经过 Apple 公证。当前版本没有应用内自动更新组件；GitHub Release 提供手动下载安装包。
