# EmberCat 0.6.20

Build 36 · 2026-11-04

Matrix 黑洞增加可调光效、随输出速度加快的心跳和代码吸入后的湮灭荧光，同时清理黑洞表面字符，让吸入过程更清楚。

## 新增与调整

- 代码到达洞缘后隐去，进入黑洞后在真实入口短暂亮起荧光，再消散；黑洞表面不再堆积旋转字符。
- 鼠标经过黑洞时柔和虚化并降低不透明度，移开后恢复。感应区域跟随黑洞大小、位置和预览缩放，桌面浮层继续穿透点击。
- 中心加入双拍呼吸光，心跳随平滑 tok/s 加快。20 / 90 / 180 tok/s 下约为 2.86 / 1.50 / 1.00 秒一轮，调速时保留心跳相位。
- 新增「中心光范围」和「洞缘光宽」两个实时滑杆，可分别缩小或放大。默认沿用确认后的光效尺寸，支持保存、重开和恢复默认。
- 洞缘光晕更窄，中心呼吸光范围稍大；原有黑洞大小、引力、密度、距离及系统深浅配色继续保留。
- 系统减少动态效果时，心跳与代码保持静止，鼠标进出仍能触发虚化和恢复；归零、关闭、休眠后停止绘制和鼠标跟踪。
- 旧的三参数、四参数 Matrix 配置可直接读取，新增光效参数采用默认 100%，原有设置不丢失。

| 新参数 | 默认值 | 可调范围 |
| --- | --- | --- |
| 中心光范围 | 100% | 50%–200% |
| 洞缘光宽 | 100% | 40%–180% |

菜单入口为「刘海特效 → Matrix 代码雨」及「特效设置与预览…」。预览使用模拟 tok/s，保存并应用后才影响顶部特效。

## 安装与更新

适用于 Apple Silicon Mac，macOS 14 或更高版本。0.6.15 及后续版本可通过「检查更新…」或自动更新获取本版；0.6.14 及更早版本需要手动安装。

DMG 与 ZIP 包含相同应用。应用沿用本地 ad-hoc 签名，未使用 Developer ID 或 Apple 公证；更新清单和 ZIP 另有 Sparkle EdDSA 签名。
