# EmberCat 0.6.15

Build 31 · 2026-11-03

本版加入 Sparkle 应用内更新，收紧刘海火焰的横向范围，并修复设置预览的绘制生命周期。

## 新增与修复

- 刘海外沿保留原来平滑的 U 形轮廓和固定粗细，让亮光沿边缘流动、渐亮渐暗；火焰主体、扰动和余烬限制在刘海左右边界之内，向下焰尾继续保留。
- 火焰预览使用独立管理的显示刷新回调；编辑速度档位、保存、熄灭后重启和重新打开窗口均保持绘制生命周期一致。
- 菜单增加「检查更新…」「自动检查更新」「自动下载并安装」。使用 Sparkle 2.10.1，从 GitHub Releases 获取更新，默认每日检查。
- 更新清单和 ZIP 更新包使用 EdDSA 签名，解压前验证更新包；更新清单固定使用最新正式 Release 中的 appcast.xml。
- 保留既有测速来源、宠物动作、Dock 小猫及荧光脚印。

## 安装与更新

适用于 Apple Silicon Mac，macOS 14 或更高版本。0.6.14 及更早版本尚无更新组件，需要手动安装一次本版；此后可通过应用内检查或自动更新获取新版本。

手动安装使用 DMG，Sparkle 使用 ZIP；两者包含相同的应用。应用仍使用本地 ad-hoc 签名，未使用 Developer ID 或 Apple 公证。更新包另有 Sparkle EdDSA 签名。

真实刘海尺寸仍由系统安全区域提供。当前本机为无刘海外接屏，实体刘海由模拟几何覆盖，尚未完成实体刘海屏真机验收。

Token 检测与测速核心来自 Agent Speed（MIT）；源码和应用内保留上游及 Sparkle 的许可声明。
