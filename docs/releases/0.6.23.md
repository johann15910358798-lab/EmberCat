# EmberCat 0.6.23 · 仓鼠发电机交互修复

Build 39 · 2026-11-05

「仓鼠发电机」统一了菜单和设置里的名称，鼠标经过时会让开，调参也不会再把设置窗口撑大。

## 本次改动

- 特效选择、设置标题、保存按钮和预览导出统一使用「仓鼠发电机」。已保存的样式和参数继续有效。
- 鼠标移到能量条或两侧仓鼠时，整组淡出隐藏；移开后恢复。隐藏期间保持点击穿透和动画连续，不需要新的测速输入才能恢复。
- 开启 macOS「减少动态效果」时，悬停隐藏、移开恢复仍有效；指针停留时不会持续重绘。
- 固定预览卡片和调参窗口的尺寸。调整能量条粗细、仓鼠大小或间距时，完整效果在预览内部适配，滑杆和保存按钮保持可见。
- 保留连续能量内流、随机闪电、三档仓鼠动画，以及原有流焰和 Matrix 的设置。

## 使用方式

在菜单中选择「刘海特效 → 仓鼠发电机」，通过「特效设置与预览…」调节参数，点击「保存并应用」后生效。预览中的 tok/s 为模拟输入，不改变真实测速记录。

## 验证与安装

原生检查通过：七个参数的范围两端和组合编辑保持窗口大小不变，54 组命中检查覆盖能量条、两侧仓鼠、缩放和参数极值；悬停淡出、移开恢复、减少动态效果及停止清理均通过。原有流焰、Matrix 的预览、保存、切换和重开回归通过。

本次实机环境为无刘海外接屏；实体刘海屏的视觉效果尚未另行验收。适用于 Apple Silicon Mac、macOS 14 或更高版本。0.6.15 及后续版本可通过「检查更新…」获取本版；更早版本需手动安装。

应用沿用 ad-hoc 签名，更新清单和 ZIP 使用 Sparkle EdDSA 签名；未使用 Apple Developer ID 或公证。
