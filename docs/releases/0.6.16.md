# EmberCat 0.6.16（历史草稿）

Build 32 · 2026-11-03

此本地草稿未作为 GitHub 正式版本发布；最终 Matrix 方案见 [0.6.19](0.6.19.md)。以下保留当时的设计记录。

新增 Matrix 代码雨刘海特效。绿色流光沿刘海外缘连续游走，三层不同大小、速度与清晰度的字符向下穿梭，形成前后纵深。少量明亮近景与隐约远景错开，亮头拖着逐渐变暗的字符，在桌面上自然消散。

- 菜单「刘海特效 → 特效样式」可切换流焰与 Matrix 代码雨，选择自动保留。
- 「特效设置与预览…」提供三种背景和模拟速度；预览选中后可单独应用到顶部。
- 代码雨独立使用翡翠绿与薄荷白配色，火焰原有的颜色、速度区间和质感设置继续保留。
- 特效随真实输出速度变化，归零、关闭或屏幕休眠后停止绘制；支持系统减少动态效果，窗口继续穿透鼠标。
- 既有安装默认保留流焰，宠物动作、Dock 小猫及自动更新继续使用原有设置。

本地预览和导出动画使用明确标注的模拟 tok/s，不代表实际 Token 输出。当前验收设备为无刘海外接屏；实体刘海尺寸和缩放由系统几何与渲染检查覆盖，尚未完成实体刘海屏真机验收。

源码版本和本地安装包不代表 GitHub Release 已公开。应用使用本地 ad-hoc 签名，发布与自动更新包需按 `docs/updates.md` 单独准备。
