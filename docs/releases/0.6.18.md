# EmberCat 0.6.18（已撤回的视觉草稿）

Build 34 · 2026-11-04

此本地草稿的旧视觉方案已撤回，未作为 GitHub 正式版本发布。经后续修改确认的 Matrix 方案见 [0.6.19](0.6.19.md)；以下内容仅保留为旧草稿记录。

Matrix 代码成束进入刘海黑区，完全隐没片刻，再从另一处流出。出入位置、路线、速度、停留时间和纵深独立生成，同一束代码保留字符身份。

- 移除整齐的竖直网格、固定螺旋、周期横扫和全局轮换节拍。
- 字符保持直立，沿曲线等距排布，明亮的头部与渐暗的尾部保留可读的流向。
- 代码穿过刘海边缘时，附近的薄荷色流光轻微提亮；黑区内完全隐藏字符。
- 每次启动采用新的随机种子，每次生成代码时继续变化；远近大小、清晰度、亮度与遮挡体现空间感。
- 刘海轮廓流光、透明桌面、既有显示边界、真实速度响应、归零停帧和减少动态效果继续生效。

菜单入口仍为「刘海特效 → Matrix 代码雨」。预览与导出明确标注模拟速度；固定种子的导出仅用于复查。本地构建和安装包不代表 GitHub Release 已发布。
