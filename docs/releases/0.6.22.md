# EmberCat 0.6.22 · 仓鼠动力能量条

Build 38 · 2026-11-05

刘海下方新增仓鼠动力能量条：两侧仓鼠随输出速度换挡，条内电流连续交织，外部随机迸出闪电，放电时整组轻微回弹。

## 新增与调整

- 接入慢速、高速、极速三档仓鼠动画，右侧镜像朝内，左右略微错开节奏。约 60 和 140 tok/s 附近平滑换挡，默认保留原始动画速度。
- 使用深色描边和黄色端盖搭配仓鼠。内流贯穿整条，去掉左右对称拼接与分段线；随 tok/s 由冷白变蓝、转紫，最高档微微泛红。
- 牵引电弧连接刘海与能量条；放电的间隔、位置、长度和形态逐次变化，单次电弧保持连接点稳定。悬浮和微颤与放电联动。
- 调参面板精简为七个滑杆和一个开关，支持即时预览、保存应用、恢复默认。仓鼠播放和能量内流独立调速，调节过程中保持动作连续。
- 仓鼠放大或拉开间距时，连接线和透明画布自动适配。兼容早期试用配置，保留已保存的能量、位置与运动设置。
- 保留点击穿透、归零淡出停帧、关闭与休眠停止、减少动态效果。原有流焰和 Matrix 设置继续有效。

| 参数 | 默认值 | 可调范围 |
| --- | --- | --- |
| 能量条粗细 | 100% | 65%–145% |
| 能量流速 | 100% | 25%–250% |
| 电弧强度 | 100% | 0–200% |
| 刘海距离 | 6 pt | 6–36 pt |
| 仓鼠大小 | 100% | 70%–150% |
| 两侧间距 | 5 pt | 0–24 pt |
| 仓鼠动画速度 | 1.00× | 0.50×–2.00× |
| 悬浮与放电微颤 | 开 | 开／关 |

## 使用方式

打开菜单的「刘海特效 → 柱状闪电」，即可启用仓鼠能量条。在「特效设置与预览…」中拖动参数可即时查看效果，点击「保存并应用」后应用到桌面特效。预览中的 tok/s 为模拟输入，不改变真实测速记录。

## 安装与验证

适用于 Apple Silicon Mac，macOS 14 或更高版本。0.6.15 及后续版本可通过「检查更新…」获取本版；更早版本需手动安装。DMG 与 ZIP 包含相同应用。

专项检查覆盖三档动画的 72 帧和原始时长、实际 GPU 缩放与间距、独立调速、随机放电、45 组显示极值、配置迁移、保存重开与原生生命周期；原流焰、Matrix 和设置界面回归通过。原生验证环境为无刘海外接屏的顶部锚点，尚未完成实体刘海屏的实机视觉验收。

应用沿用 ad-hoc 签名，未使用 Developer ID 或 Apple 公证；更新清单和 ZIP 另有 Sparkle EdDSA 签名。
